leavs 公共 APT 软件源

统一分发 leavs 的 Linux 工具。只需添加一次软件源，即可安装后续上架的新工具。

可安装的软件

包名版本架构下载

每个工具的系统要求请查看 Release；目前 Camera 支持 Ubuntu 24.04 amd64。提供 arm64 索引不表示所有工具都有 arm64 包。

添加软件源

sudo apt-get install -y ca-certificates curl gnupg
curl -fsSL https://leavs.github.io/apt/apt-key.gpg -o /tmp/leavs-apt-key.gpg
gpg --show-keys --with-fingerprint /tmp/leavs-apt-key.gpg

核对指纹：AFA7 A554 83A3 A25D 6B1C EF37 9307 7871 3952 5089，然后执行：

sudo install -d -m 755 /etc/apt/keyrings
sudo install -m 644 /tmp/leavs-apt-key.gpg /etc/apt/keyrings/leavs-tools.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/leavs-tools.gpg] https://leavs.github.io/apt/ stable main" | sudo tee /etc/apt/sources.list.d/leavs-tools.list
sudo apt update
sudo apt install usb-camera-preview
